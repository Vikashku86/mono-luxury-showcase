# Monochrome Portfolio

Create a premium Full Stack Developer portfolio with a minimal black and white theme.

Design Style:

- Pure black background (#000000)

- White typography (#FFFFFF)

- Light gray secondary text (#A1A1AA)

- White borders with low opacity

- Clean, modern, luxury aesthetic

- No colorful gradients

- No neon effects

- Minimal and elegant design

- Plenty of whitespace

- Smooth scrolling

- Glassmorphism only where necessary

- Subtle hover animations

- Soft shadows

- Rounded corners (16px)

Layout:

- Sticky transparent navbar

- Large hero section

- Professional About section

- Modern Skills grid

- Premium Project cards

- Experience timeline

- Contact section

- Minimal footer

Typography:

- Large bold headings

- Clean sans-serif font (Inter or Geist)

- Excellent spacing and readability

Animations:

- Framer Motion

- Fade-in on scroll

- Smooth card hover

- Button micro-interactions

- Subtle section transitions

Buttons:

- Primary: White background with black text

- Secondary: Black background with white border and white text

The portfolio should look clean, modern, premium, and suitable for software engineering job applications. Prioritize simplicity, elegance, and readability over flashy effects.
